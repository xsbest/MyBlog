# Flutter入门到精通｜本地化开发调试

> 从零搭建相册项目到真机调试，梳理了本地持久化、录音/播放、相册导入、权限配置、Xcode/Pods 问题与热更新的完整路径。

## 背景

需求是做一个相册回忆录应用，包含时间线浏览、目录管理、录音留言与手机相册导入。环境上需要同时支持 macOS 桌面调试与 iPhone 真机调试。

## 关键结论

- 热更新是否生效取决于 Flutter VM 是否成功附加，单纯 “r/R” 不会修复连接问题。
- iOS 真机调试常见瓶颈是 CocoaPods 链路和本地端口转发（iproxy）。
- 使用本地持久化后，修改 sample_data 不会生效，需要手动重置数据。

## 过程与实现

### 1. 本地持久化与数据流

- 使用 `AlbumRepository + AlbumStorage` 管理相册数据。
- 首次启动将 `sample_data` 写入本地 JSON，后续启动全部从本地读。
- 增加“重置示例数据”入口，支持重新导入 `sample_data`。

关键路径：

- `lib/data/album_repository.dart`
- `lib/data/album_storage.dart`

### 2. 录音与播放

- 录音：使用 `record`，保存到 app 文档目录。
- 播放：使用 `just_audio`，播放完成后自动复位 UI。
- 对示例数据做了“无文件提示”，避免误以为播放失效。

关键依赖：

- `record`
- `just_audio`

### 3. 相册导入（>1MB，去重）

- 使用 `photo_manager` 扫描设备相册。
- 过滤小于等于 1MB 的图片。
- 通过 `originAssetId` 去重。
- 拷贝图片到应用私有目录，保证后续可展示。

关键路径：

- `lib/data/album_repository.dart` -> `importDevicePhotos()`

### 4. 权限配置

- Android：`READ_MEDIA_IMAGES`（13+）+ `READ_EXTERNAL_STORAGE`（<=32）+ `RECORD_AUDIO`
- iOS：
  - `NSMicrophoneUsageDescription`
  - `NSPhotoLibraryUsageDescription`
  - `NSPhotoLibraryAddUsageDescription`

### 5. iOS 真机调试与 Xcode

关键经验：

- 必须用 `ios/Runner.xcworkspace` 打开。
- `Pods_Runner not found` 通常是 Pods 断链或打开了 `.xcodeproj`。
- 修复流程：
  - `flutter clean` -> `flutter pub get` -> `pod install`
  - Xcode `Clean Build Folder`

### 6. 热更新失效排查

常见现象：

- “Installing and launching…” 卡住
- “Dart VM Service not discovered”
- “Unexpectedly found more than one Dart VM Service report”

原因与解决：

- iOS 端口转发工具 `iproxy` 被 Gatekeeper 阻止。
- 清理 Flutter 自带工具的 quarantine：
  - `xattr -dr com.apple.quarantine /path/to/iproxy`
- 指定 VM 端口避免冲突：
  - `flutter run -d <device> --host-vmservice-port=50555`

## 风险与注意事项

- macOS/iOS 插件警告多数是第三方 SDK 的旧 API 提示，通常不阻塞。
- 修改 `sample_data` 不会自动生效，因为本地持久化已覆盖样例。
- iOS 真机调试必须保持 `flutter run` 会话，单独打开 app 不支持热更新。

## 结果验证

- `flutter analyze` 仅残留 info 级别 lint。
- macOS 与 iPhone 均可运行并建立 VM Service。
- 录音/播放、相册导入流程可用。

## 附录

常用命令：

```bash
flutter clean
flutter pub get
cd ios && pod install
flutter run -d <deviceId>
flutter run -d <deviceId> --host-vmservice-port=50555
```

调试入口：

```sh
# Xcode
open ios/Runner.xcworkspace

# Flutter
flutter run -d <deviceId>
```
